《晒》双角色规则测试器 0.2.0
========================================

运行方法
----------------------------------------
方法一：双击“启动游戏.bat”。
方法二：在本目录执行 python main.py。
方法三：若目录中已有“晒_双角色规则测试器.exe”，直接双击EXE，不需要Python。

首版功能
----------------------------------------
- A、B各选择一个人物，依次选招；双方都选完后按防御和先制统一结算。
- 技能使用紧凑按钮网格显示；悬停显示伤害、效果、对应防御、距离、先制和角色特殊效果。
- 支持防御1～4、平面镜反弹和憋神技，防御成功不受先后手影响。
- 支持收集/使用万灵丹、收集即生效的万能胶，以及欧阳修收集/使用酒。
- 显示体力、盾牌、生命条数、场景高度、内功、所有当前状态、寄生虫、辐射、物品和计数器。
- 列出当前角色的全部动作；因封禁、资源、场景、距离等原因不能执行的动作自动灰显。
- 执行基础伤害、盾牌不溢出、状态、寄生虫、场景、资源、内功、多条命和部分人物覆盖规则。
- 对战记录只显示实际结果，可另存TXT；也可保存JSON完整状态。
- 使用固定随机种子可复现流星、闪避、射线、秒杀等随机结果。

强化学习接口
----------------------------------------
rl_env.py 中的 ShaiEnv 不依赖Gymnasium，提供：
- reset(seed, character_a, character_b)
- legal_actions()
- action_mask()
- step(action_id, destination=None)
- numeric_observation(perspective)

GUI和强化学习接口共用engine.py中的GameEngine。后期接Gymnasium、Stable-Baselines3、
PettingZoo或自写多智能体算法时，只需要新增适配层，不应复制或重写规则。

多人和网页扩展接口
----------------------------------------
extension_api.py提供BattleSessionProtocol、GameCommand、CommandResult和GameSessionAdapter。
未来服务器或WebSocket层只调用snapshot / available_commands / submit / subscribe，
不依赖Tkinter，也不直接修改人物内部状态。具体兼容约定见“扩展接口说明.txt”。

自动测试
----------------------------------------
执行：python -m unittest -v test_engine.py

规则边界
----------------------------------------
“歧义与待确认规则.txt”列出了没有被#回答、被明确暂缓或仍缺少输入方式的规则。
首版对这些内容使用保守的临时假设，避免把猜测包装成正式规则。
