## 读不准的地方

1. 「大难不死」的条件：写在涂改带上，墨水很淡。「学」和「20,30次……」看得清；前面两个数读作 [?5] 和 [?10]（和效果里的四个数 10%、20%、30%、40% 能对上）。位置：约 (780–1500, 640–760)。
2. 「大难不死」和「凌波微步」之间的一整行：贴了涂改带，空白，看不出原来写了什么。位置：约 (300–2700, 760–900)。
3. 「幸运」的效果里的「2/3」：是补写在行间的小字，「2」「3」能认出来，中间的分数线和旁边的笔画挤在一起。位置：约 (2110, 1640)。
4. 「弹性形变」的效果「反弹25%[?n]基伤」：「25%」后面有一个像小写字母 n（也像「几」）的笔画，后面的「基」字是在别的字上重描的。这个 n 可能是「的」的简写，也可能是被改掉的字剩下的笔画。位置：约 (2340, 2320)。
5. 「弹性形变」的效果「限度20000[?N].（<）」：「20000」写得很小；后面紧跟一个像大写 N 的笔画和一个小点，再后面是括号里一个小于号「<」。N 可能是力的单位（牛顿）。位置：约 (2700–2960, 2270–2360)。
6. 「放射性」的条件第三个数：[?50]。字形是「50」，但它夹在 200 和 500 之间，顺序不对，有可能是「350」少写了一笔，也有可能就是 50。位置：约 (1190, 2960)。
7. 「昏沉大法」效果里「全场」后面的符号：像字母 G，也像一个螺旋。照片 d690bc7265b46866ca11beaec63896bb.JPG 的图标表里「像数字 6 的螺旋」表示昏睡，这里很可能是同一个符号。位置：约 (2390, 2610)。
8. 物品第二行第二个字：[?涤/绦]。字形是左边两三点、右边上「土」下「木」，最像「涤」；按意思可能是「绦」（绦虫）。位置：约 (860, 3590)。
9. 物品第二行的「[?涤/绦]」和「虫」：中间隔着一个小图标（三个连环）。可以理解成两个物品（「绦」和「虫」各带一个图标），也可以理解成一个物品「绦虫」，中间插了一幅小图。原文看不出是哪一种。
10. 「暴击」效果里的「必中」：两个字写得很草，读作「必中」比较有把握。位置：约 (2480, 2140)。
11. 对页的残字（不属于本页）：圈里的字除了「先」以外都看不全。

## 缩写和符号

- 学 N 次 / 学 N 下：学这个内功的次数达到 N（本页没有解释怎么算「学一次」）。一行里有几个数，对应效果栏里依次的几个数值，应该是内功的第 1、2、3、4 级。
- △：写在「重贼」「内功栏」「放射性」三个名字后面。本页没有解释，含义不明。
- ?：写在「弹性形变」「昏沉大法」两个名字后面（写在涂改带上）。本页没有解释，含义不明。
- 贼：猜拳。「贼输了可重贼 1、2、3 次」是说猜拳输了可以重新猜 1、2、3 次。
- 闪率：闪避的概率。
- 消特效：消除（对方招式的）特效。「（可消）」里的「消」也是这个意思。
- 基伤：基础伤害的简写（本页上面写「基础伤害」，下面写「基伤」）。
- 必中：一定打中。
- 限度20000[?N]（<）：本页没有解释。从字面看是「反弹只对 20000 以下的伤害有效」，含义不明。
- 【螺旋符号，像 G】×1：很可能是「昏睡一回合」的记号，本页没有解释。
- α、β、X、γ射线：α射线、β射线、X光、γ射线。
- 上一层 / 下一层：场景往上或往下移动一层（场景的分层见照片 de7af104f2c8d54276ed5b0785335734.JPG）。
- 内功栏：「在 3 个基础上增加 1、2、3 个内功」，说明一个人原本可以带 3 个内功。
- 先手出招：比对方先出招。
- 【圈里一个「核」字】：核弹的图标。
- 【圈里一个「先」字】：只出现在对页的残字里，不属于本页。
