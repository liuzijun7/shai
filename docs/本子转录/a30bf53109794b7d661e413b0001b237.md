## 读不准的地方

1. ② 第二行"免疫火?特效"（约 x 1290–1410, y 840–955）："火"后面的字上面像"幺"，下面像"小/心"。读作"系"。
2. ⑥ 第二行"绝招?憋"（约 x 1990–2130, y 2190–2350）："招"和"憋"之间的字，右边是清楚的"可"，左边多出一竖一撇和一小点，和"可"共用上面一横。候选："不可"（两个字挤在一起）、"可"（左边是写错后的笔画）、"何"。这关系到龙王的绝招能不能被憋。③ 饕餮那里写的是清楚的"绝招必中可憋"。
3. ⑦ 第三行末尾"可以?"（约 x 2740–2920, y 2900–3070）：左边像"马"（也像"弓"），右边三竖像"川"。候选："驯"（驯木乃伊）、"引川"两个字。
4. ⑧ 第三行"可以超?占卜"："超"后面的字上面是"隹"、下面是"木"，照笔画是"集"；也可能作者想写"超级占卜"。
5. ⑤ 第二行"内爆3级"：两个字照笔画是"内爆"。任务词汇表的内功里没有这个名字。
6. ① 第三行"昏沉大法3"："昏"字写成上"氏"下"日"两截，读作"昏"。

## 缩写和符号

- ①–⑧：人物编号。
- "血"：血量。"上限"：血量上限。"上限无限""血上限无限"：没有上限。"可以破上限"：可以超过上限。
- "N级"：内功的等级（虚空神术3级、幸运3级、大难不死3级、幻影4级、内爆3级、凌波微步3级、全内功3级）。"全内功"：全部内功。
- "学内功一下算三下"：学内功时做一下算三下。"下"是"一次（一个回合的动作）"的意思，本页没有另外解释。
- "憋"：本页没有解释。从用法看是把对方的招挡回去："出招憋不回去""绝招必中可憋""憋神技时"。
- "绝招"：人物自己的大招。"(必中)"：一定命中。
- "特效回合×2"：特效持续的回合数翻倍。"不良特效无效""场景不良效果无效"：坏的特效 / 场景的坏效果对他不起作用。
- "可以打到所有地方""全宇宙"：看起来是说攻击不受场景限制。本页没有解释。
- "神技无限伤害×4""神技×4"：神技的伤害乘 4（"无限"可能指无限模式）。本页没有解释。
- "进化""衰变"：人物形态的变化；"5条命后进化""收5个水之能量进化""20回合衰变"。本页没有解释细节。
- 〔螺旋〕：见"图画"。"〔螺旋〕时每回合+30000"，看起来是"处在这个状态（可能是昏睡）时每回合加 30000 血"。本页没有解释这个符号。
- "+30000"：每回合加 30000（血）。
- "金字塔元素""水之能量"：收集用的东西，数量够了可以造金字塔 / 进化。
- "下数×10000"：占卜大师占中时，血和上限各加"下数×10000"；"下数"指什么本页没有解释。
- "有放射性"：纵目青铜怪带的属性，本页没有解释。
