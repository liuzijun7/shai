## 读不准的地方

1. 免疫栏第二行"【火苗形】(圈:?)、地心"属于哪个人（约 (2630, 380, 2890, 490)）：按行的走向它对着武圣，但它的位置比武圣那一行略低，也可能是饕餮的。武圣和饕餮在别的页上的说明可以用来核对。
2. 同一处的 `(圈:?)`：圆圈里的字描得很粗，像"山"、M 或"凶"的形状，读不出。它和招术表里真火的特效符号（圈里像 M）长得很像，可能是同一个符号。
3. 埃及法老的免疫栏（约 (2835, 940, 2935, 1050)）：修正带上写着一个大的"×"（左下角带一个小钩）。可能表示"没有 / 不免疫"，也可能是把原来的勾改成了叉，也可能是字母 X。
4. 占卜大师的进化版（约 (2990, 990, 3290, 1150)）："(金字塔)"下面有两行叠在一起的字。上面一行被涂改得很重，只能看出最后两个字像"大仙"；下面一行是"魔法师"。按"上面一行被划掉、改成魔法师"理解。
5. 拳术宗师的进化版（约 (3030, 1270, 3290, 1480)）："赵先龙"三个字的下半部分压着另外三个字，像"超大仙"（第一个字也可能是"趣""起"）。没有明显的删除线，按"先写了?大仙、后来在上面改写成赵先龙"理解。
6. 巫师的内功"幻3.5"：3 和 5 之间有一个点，读作 3.5，也可能是"3, 5"。
7. 宋濂的"憋大招"：修正带上写的是一个问号"?"（下面带一个点），照原样写。
8. 宋濂的大招"换人"和范仲淹的大招"洪水"：按位置，"换人"在宋濂这一行，"洪水"在范仲淹这一行。但本子别的页写的是"范仲淹换人""范仲淹…洪水淹一层"，所以"换人"也可能本来是范仲淹的（写高了一行）。

## 缩写和符号

- 内功一栏用的是内功名的第一个字加等级数字，本页没有写全称。按内功表对应应是：虚 = 虚空神术，幸 = 幸运，大 = 大难不死，幻 = 幻影，凌 = 凌波微步，蛮 = 蛮力，铁 = 铁布衫，暴 = 暴击，弹 = 弹性形变，轻 = 轻于鸿毛。后面的数字是等级（如"虚3"是 3 级）。
- 憋大招：每格填"可"或"不"（"憋"是挡掉对方的招）。本页没有解释是哪个方向：可能是"这个人的大招能不能被别人憋"，也可能是"这个人能不能憋别人的大招"。库巴这一格是"不"，而本子另一页写库巴"不可憋"，所以前一种理解的可能性大一些。
- 大招一栏也是简写，本页没有写全称：
  - 内功学×3、内功学×5：像是"学内功一下算三下 / 五下"。
  - 一, 二, 七, 十二：像是武一式、武二式、武七式、禁十二式。
  - 究, 牙, 燃牙：像是究极吸取、饕餮牙，"燃牙"含义不明。
  - 洪、地、寒：像是洪水、地震、寒潮。
  - 云, 麒芒：像是云端之星、麒麟芒星。
  - 换血、辐射、神技、全部魔法、换人、洪水、无敌、γ射线、生物、化学：字面意思。
- 全宇宙：打勾表示这个人可以打到所有场景（"打全宇宙"）。本页没有解释。
- 大招必中：打勾表示大招一定命中。
- 免疫：这个人不受哪一类招术影响。B、M、T、W、C 是招术属性的字母，本页没有解释；从别的页看，M 像"魔法"、T 像"特技"、W 像"物理"、C 像"化学"、B 像"生物"。
- 进化版：这个人进化之后的名字。括号里的"(金字塔)""(岳阳楼)"不像人名，像是和这个人相关的东西（建筑 / 物品），含义本页没有解释。
- ☆：只标在"超级真身"前面，含义本页没有解释。
- 十万×2、(三十万+十万)×3、十万+3×十万、五万+十万、二十万+十万：血量的写法。"×2""×3"像是几条命，"+十万"像是额外的盾牌，本页没有解释。
- 加命：写在饕餮的血上限里，像是"还可以加命"，本页没有解释。
- `【火苗形】`、`(圈:?)`：状态符号，含义本页没有解释。
