## 一、方向和产品

### A1 整体方向
规则继续用刘同学的 Python 规则引擎，放在服务器上跑；玩家用浏览器打开网页来玩。这个方向可以吗？

- 默认：保留 Python 引擎，做网页客户端。

### A2 规则以哪一份为准
本子、规则文档（`晒的人物技能规则.docx`）、刘同学引擎里的数据，三份的数值对不上（对照表在 `docs/工作进度.md` 第 7 节）。例如无限模式下麒麟芒星，本子写 10000，引擎里是 30000。以哪份为准？

### A3 先做哪个模式
你说游戏分两段：早期“有限晒、有限毒”，要先收集资源才能出招；后来不管资源，直接出招，体力和伤害都很高。本子里把后者叫“无限模式”。第一版做哪个？

### A4 一局怎么打

### A5 设备

### A6 登录

### A7 要不要电脑对手

### A8 限时

### A9 附加功能

## 二、“贼”的规则

### B1 贼的基本形式
石头、剪刀、布三选一，双方同时出，同时揭晓。打平怎么办？
- 默认：决定先后手的贼，打平就重来，直到分出胜负。决定概率的贼见 B5。

### B2 什么时候要贼
双方先制相同时：
- (a) 一律贼。
- (b) 只在“谁先谁后会影响结果”时才贼。例如一方出摄魂大法、另一方出魔法攻击，先后有区别，要贼。两边都是普通攻击而且谁也打不死谁，先后没区别，不贼。
- 为什么问：(a) 的话几乎每回合都要贼，联机时每回合多等一次，节奏慢。
- 默认：(b)。电脑会在暗地里把两种顺序各算一遍，结果不同才让你们贼。

### B3 贼赢了意味着什么
- (a) 赢的人先出手。
- (b) 赢的人来决定谁先出手。
- 为什么问：少数情况下后出手反而有利。
- 默认：(a)。

### B4 一回合里好几处都要贼
- (a) 每处各贼一次。
- (b) 回合开始贼一次，结果管整个回合。
- 默认：(a)，但同一个回合里“谁先出手”只贼一次。

### B5 概率怎么用贼实现
你举的例子是“三分之一概率复活，贼赢了才算”。贼一次，赢、平、输各占三分之一，所以可以这样对应：

| 概率 | 贼法 |
|---|---|
| 1/3（33%） | 贼一次，赢了才算 |
| 2/3（66%） | 贼一次，不输就算 |
| 1/2（50%） | 贼到分出胜负，赢了算 |
| 1/4（25%） | 连赢两次（打平重来） |
| 1/8（12.5%） | 连赢三次 |
| 10%、30% 这类 | 没有自然的贼法 |

规则里出现过的概率有：10%、12.5%、25%、30%、33%、50%、66%。问题：
1. 上面的对应关系对吗？你们当年是怎么做的？
2. 是所有概率都用贼，还是只有一部分用贼、其余让电脑掷随机数？
3. 10%、30%（α 射线、β 射线）怎么办？
- 默认：1/3、2/3、1/2 用贼；其余由电脑掷随机数。

### B6 概率的贼，谁算“赢”
- 给自己带来好处的判定（大难不死、幸运、闪避）：受益的人贼赢了才生效？
- 给对手带来坏处的判定（死亡笔记秒杀、硫酸秒杀、臭伽马）：出招的人贼赢了才生效？
- 默认：都是“想让它生效的那个人”要赢。

### B7 “憋回去”到底是什么效果
你说摄魂大法先生效时，对面的魔法攻击“被憋回去”。刘同学的引擎现在是：后手的招如果被先手封住，**自动变成普通攻击**，照样打 10000。哪个对？
- (a) 变成普通攻击（引擎现状）。
- (b) 完全作废，这回合什么都不做。
- 默认：没有默认，这条必须你来定。

### B8 两个神技同时出
你说神技优先级最高，两个神技一起出还是要贼。贼输的一方：
- (a) 神技照常放，只是后放。
- (b) 神技作废。
- 另外，引擎里“憋神技”是一个单独的防御动作：有人出了它，场上所有神技变成普通攻击，出神技的人被封神 3 回合。这个和贼是什么关系？两个都保留吗？
- 默认：(a)；“憋神技”保留原样。

### B9 “重贼”是什么
规则文档里蚂蟥大仙的内功写着“重贼 2”，刘同学的清单里也问了“重贼 2/3 是不是重于泰山的简称”。它是不是“贼输了可以重新贼 N 次”的意思？
- 默认：没有默认，需要你解释。

### B10 库巴的“回合开始时贼扔 or/and 跑”
具体过程是什么？和谁贼？赢了能做什么？“扔”和“跑”分别是什么效果？各贼一次还是一次定两样？

### B11 回合开始时的效果撞在一起
龙王“每回合开始时移动对手场景”，牛顿“回合开始时可以选择自己的场景”，库巴“回合开始时扔和跑”。规则文档里三处都写了“和龙王的关系？”。龙王对牛顿时，龙王把牛顿移走，牛顿又把自己移回来，最后算谁的？
- 默认：两个效果互相抵消时就贼，贼赢的人说了算（上面的例子里，牛顿赢了就留在自己选的场景，龙王赢了牛顿就被移走）。

### B12 透视类效果在联机时怎么实现
纵目青铜怪“登场后下一回合透视对手技能，之后每隔一回合透视一次”。联机时双方是同时暗选的。要透视就得让对手先选完，再把他的选择给青铜怪看，然后青铜怪再选。是这个意思吗？被透视的一方知道自己被看了吗？
- 默认：是这个意思；被透视的一方会看到提示。

### B13 时间点
你提到不想要赛尔号那么多时间点。我的建议是只留四个：回合开始、出招、回合结束、死亡。所有人物的被动效果只能挂在这四个点上，不设固定先后号，撞了并且先后有区别就贼。详见 `docs/调研/03-结算中途暂停与先后顺序.md` 第 4 节。可以吗？
- 默认：可以。

### B14 同一个人自己的两个效果撞了
比如自己的内功和自己的招同时要生效。这不涉及对手，贼不合适。
- 默认：按固定顺序（先内功，后招式）；以后发现有问题再让玩家自己选。
